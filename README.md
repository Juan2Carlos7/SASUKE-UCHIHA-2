# Kino TV · Tema Sasuke Uchiha

Temas inspirados en Sasuke Uchiha para **Kino TV**: Sharingan, Rinnegan y Chidori.

## Temas incluidos

- **Sasuke Uchiha** — rojo Sharingan sobre negro, con el Mangekyō Sharingan.
- **Rinnegan** — morado con los anillos del Rinnegan.
- **Chidori** — azul eléctrico.

## Instalación

1. Abre Kino (versión 0.9.81 o más nueva) ▸ **Ajustes** ▸ **Plugins**.
2. Escribe `tu-usuario/tu-repositorio` o pega el enlace directo al manifiesto:
   `https://raw.githubusercontent.com/tu-usuario/tu-repositorio/main/kino-plugin.json`
3. Ve a **Ajustes** ▸ **Apariencia** y elige «Sasuke Uchiha», «Rinnegan» o «Chidori».

## Archivos

- `kino-plugin.json` — manifiesto del plugin con los 3 temas.
- `plugin.js` — punto de entrada del plugin.
- `icon.png` — icono del plugin (Sharingan).

## Actualizaciones

Al subir cambios, incrementa `version` en `kino-plugin.json` (ej. `1.0.0` → `1.0.1`) para que los usuarios reciban la actualización.
